# Navigator Mini App

Мобильный интерфейс закрытого потока Navigator. Здесь только статические файлы сайта.
Токен Telegram-бота, сервер, нативный аддон, список друзей и изображения в репозитории не хранятся.

## GitHub Pages

В Settings → Pages выбери Deploy from a branch → main → / (root).
Адрес сайта: https://ridanopium-oss.github.io/navigator-miniapp/ .

Navigator на ПК должен поддерживать Pages и быть доступен по HTTPS.
На сервере укажи `app_url` этого сайта, чтобы разрешить запросы именно с его origin.
При первом входе в mini app введи HTTPS-адрес подключения с ПК. Он сохраняется на телефоне;
после смены временного туннеля введи новый адрес. При постоянном адресе его можно задать в config.js.

Авторизация проверяется сервером через Telegram initData и разрешённые Telegram ID.
Сессионный ключ хранится только в памяти страницы. Обычное открытие сайта без Telegram не даёт доступ к данным.
Создание картинки и работа сервера выполняются на ПК; GitHub Pages раздаёт только интерфейс.
